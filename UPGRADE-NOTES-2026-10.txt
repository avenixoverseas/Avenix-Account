Deployment guidance
1. Back up production database and static website files.
2. Review the canonical schema against the live database before applying SQL.
3. Deploy the static files while preserving the Supabase public configuration.
4. Deploy the admin-user-management Edge Function with server-side secrets configured.
5. Test with the administrator and a separate staff account with limited VIEW grants.

The frontend source does not prove that production RLS or Storage policies are current. Validate those policies in Supabase and test with real authorized accounts before relying on the deployment.
